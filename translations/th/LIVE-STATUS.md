## กลุ่มที่ผู้ใช้ให้ตรวจเป็นอันดับแรก
- การต่อสู้ (Combat): ครบ62/62หัวข้อย่อย รวมความเสียหาย/ฟื้นพลัง/ความตาย พาหนะและใต้น้ำ — [หลักฐาน003](review/semantic-003.json) ต่อจาก[หลักฐาน002](review/semantic-002.json)
- การร่ายเวท/สมาธิ (Spellcasting): ครบ33/33หัวข้อย่อย — [หลักฐาน002](review/semantic-002.json)
- การพัก/พักฟื้นใน Adventuring: เฉพาะ Resting, Short Rest, Long Rest, Recuperating ครบ4หัวข้อที่เลือกจาก30 ไม่ถือว่าผ่านทั้งบท — [หลักฐาน003](review/semantic-003.json)
- ชุดแรก12บท: Conditions (ทั้ง15สถานะ), Bless, Cure Wounds, Healing Word, Magic Missile, Shield, Fireball, Hold Person, Counterspell, Dispel Magic, Sleep, Haste — [หลักฐาน001](review/semantic-001.json)

แก้เงื่อนไข/คำกำกวมพร้อมต้นฉบับและ hash ของข้อความทุกชุดแล้ว ทั้ง source/translation/section hashes, ตัวเลข/ลูกเต๋า/ลิงก์/โครงสร้าง Markdown และข้อความที่สร้างเข้าเกมผ่านการตรวจ Existing overlay checks และ Thai regressions7ข้อผ่าน

เวทที่ตรวจเพิ่ม12บท: Spare the Dying, Revivify, Raise Dead, Resurrection, True Resurrection, Gentle Repose, Death Ward, Heal, Regenerate, Prayer of Healing, Lesser Restoration, Greater Restoration — [หลักฐาน004](review/semantic-004.json)

แก้จุดที่ตกคำว่า “ยังมีชีวิต” ของ Spare the Dying และ Construct ของ Heal ที่แปลผิดเป็นสิ่งก่อสร้าง พร้อมตรวจเวลาหลังตาย ความยินยอม/อิสระของวิญญาณ วัตถุดิบใช้หมด ผลหลังชุบชีวิต และข้อยกเว้นโรค/คำสาปแล้ว

ขอบเขตกติกาหลักที่เลือกครั้งนี้รวม99หัวข้อย่อย (Combat62 + Spellcasting33 + Adventuring4) และเวทที่เกี่ยวข้อง12บท ตรวจแล้ว ทั้งนี้ยังไม่ใช่การตรวจรายละเอียดเวททุกบทหรือทั้งเกม

ถัดไป: เวทที่เกี่ยวข้องกลุ่มเยียวยาหมู่/ป้องกันเพิ่มเติมหากทำต่อในกลุ่มนี้ UI/ข้อความระบบ/เนื้อหา JSON และข้อยกเว้นเทคนิคยังรอตรวจแยก ไม่อนุมัติข้อความซ้ำโดยอัตโนมัติ ยังไม่ผ่าน production build หรือการทดสอบ UI จริงรอบสุดท้าย
