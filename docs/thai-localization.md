# ภาษาไทยสำหรับ Open Game Master

สถานะ: รุ่นเริ่มต้นบน `codex/thai-localization` อิง upstream `cc0425c2` (0.31.0)

## วิธีเลือกภาษา

- ภาษาเมนู: หน้าเข้าสู่ระบบ หรือเมนูบัญชี → ไทย หรือหน้า Settings เป็นค่าของเบราว์เซอร์นี้ สลับกลับ English ได้ ไม่เปลี่ยนภาษาของผู้เล่นคนอื่น
- ภาษาเรื่อง: Table language → ไทย (Thai) ในหน้าสร้างแคมเปญหรือการตั้งค่าโลกภายในแคมเปญ AI ใช้ภาษานี้ร่วมกันทั้งโต๊ะ
- เริ่มเกมแฟนตาซีด้วย High fantasy หรือ Dark fantasy ตามบรรยากาศที่ต้องการ ไม่จำเป็นต้องสร้างโลกใหม่เพื่อให้เล่าไทย
- การบรรยายด้วยเสียงยังขึ้นกับความสามารถภาษาไทยของผู้ให้บริการเสียง ไม่ได้เปลี่ยนเครื่องเสียงหรือโมเดลให้อัตโนมัติ

## แนวภาษา

เล่าให้เห็นฉากด้วยรายละเอียดที่มีความหมาย เช่น แสง เสียง กลิ่น และร่องรอยของเหตุการณ์ ให้บทพูดสะท้อนบุคลิกและความสัมพันธ์ ไม่ใช้คำโบราณจนอ่านยาก ไม่เล่าตัดสินใจแทนผู้เล่น และไม่เปิดเผยแผนลับของ GM

ตัวอย่าง: “แสงสุดท้ายลับแนวสน หอระฆังร้างเบื้องหน้ากลับส่งเสียงขึ้นหนึ่งครั้ง ทั้งที่ชาวบ้านยืนยันว่าไม่มีผู้ใดขึ้นไปบนนั้นมาเกือบยี่สิบปี”

กติกาต้องกระชับและตรงข้อเท็จจริง: สร้างบรรยากาศได้ แต่เพิ่ม damage ระยะ หรือผลของเวทเองไม่ได้

## ชื่อและกติกา

- หน้าจอที่รองรับแสดง `ลูกไฟ (Fireball)` และใช้ `Fireball` ส่งให้ engine เช่นเดิม
- แยกชื่อ spell `Shield` (โล่มนตรา) จาก item `Shield` (โล่) ตามประเภท ไม่ค้นด้วยชื่อไทยไปแทน canonical ID
- ในบทเล่า AI ใช้ชื่อกฎอังกฤษเดิมและเว้นช่องว่างรอบชื่อเหล่านั้น เพื่อเข้ากับตัวจับชื่อเดิม
- ชื่อที่ผู้เล่นตั้งเอง ชื่อโลก และ homebrew ไม่ถูกแปลทับ
- คำอธิบายไทยในหน้ารายละเอียดเป็นคำอธิบายย่อเพื่อช่วยอ่าน ไม่แทนกติกาฉบับเต็มอังกฤษที่ยังแสดงอยู่ ตรวจตัวเลข ข้อยกเว้น concentration และผลเมื่อ upcast จากต้นฉบับ
- ไฟล์คำแปล: `src/lib/i18n/messages.ts` และ `src/lib/i18n/content.ts` แก้เป็นรายศัพท์ได้โดยไม่แก้ข้อมูล SRD หรือเซฟ

## ขอบเขตรุ่นเริ่มต้น

มีคำแปล UI 188 ข้อความ และชื่อเนื้อหา 148 รายการ: เวท 70, ไอเทม 24, สถานะ 15, คลาส 12, เผ่าพันธุ์ 9, ทักษะ 18 คำอธิบายย่อ 20 รายการ

UI ที่เชื่อมแล้ว: เมนูบัญชี เมนูเริ่มเล่น หัวข้อร่วม ตัวเลือกทั่วไป บางส่วนของ wizard สร้างแคมเปญ การตั้งค่าภาษา ตำราเวท และรายการค้นเนื้อหา คำแปลที่ไม่มีใช้ข้อความอังกฤษเดิม ไม่ถือว่าแปล UI/แค็ตตาล็อกทั้งหมดแล้ว

## ความจำไทย

ตัวค้นแบบ lexical ใช้ `Intl.Segmenter('th')` แบ่งคำภาษาไทย คำไทยคงรูปเดิม อังกฤษผสมยังใช้ English stemmer ไม่มีการสมมติว่ามี Snowball Thai stemmer ส่วน exact-name identity ของ engine ใช้กฎเดิม

การทดสอบ fixture ยืนยันได้เฉพาะการจัดอันดับจากข้อมูลตัวอย่าง ไม่ใช่หลักฐานว่าความจำระยะยาวในเกมจริงแม่นแล้ว โมเดล embedding เริ่มต้นเป็นอังกฤษ ต้องวัดโมเดลหลายภาษาที่รองรับไทยและให้เวกเตอร์ 384 มิติ ก่อนสลับใช้งานจริง ดู `install.md` และ `storage.md` การเปลี่ยนโมเดลทำให้ reindex จึงควรสำรองเซฟก่อน

## ตรวจสอบ

```bash
node scripts/test-thai-localization.mjs
node scripts/test-language.mjs
node scripts/test-table-language.mjs
node scripts/test-table-language-calls.mjs
node scripts/test-fusion.mjs
npx tsc --noEmit --incremental false
npm run lint
npm run build
ODM_BROWSER=/usr/bin/google-chrome node scripts/browser/run.mjs --only thai-localization
```

ชุด browser ใช้ฐานข้อมูลทดสอบแยกจากเซฟจริงและตรวจทั้ง desktop/phone การทดสอบ app shell ต้องมี client build เพิ่มเติม ชุด mock ไม่ยืนยันคุณภาพการเล่าจาก AI จริง ต้องตั้ง storyteller และเล่นอย่างน้อยสิบเทิร์นเพื่อประเมินสำนวน ความต่อเนื่อง และการใช้เครื่องมือ
