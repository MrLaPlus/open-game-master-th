# Codex เป็น AI DM

ค่าที่ผู้ใช้เลือกวันที่ 2026-10-29 คือ **GPT-6 Luna / Light** ใช้รหัส `gpt-6-luna` และ reasoning effort `low` ตาม catalog ของ Codex ที่ติดตั้ง ใช้โมเดลเดียวกันสำหรับงานสรุป/จัดความจำ ไม่เปลี่ยนโมเดลเริ่มต้นของแอป Codex หรือแชทอื่น

ระบบเกมมี Codex adapter อยู่แล้ว ใช้ `codex app-server` กับบัญชีที่ล็อกอินในเครื่อง ตั้งใน **Admin → Agent program**:

- Text provider: Agent program / harness
- Program: Codex
- Story model และ Bookkeeping model: `gpt-6-luna`
- Effort และ Bookkeeping effort: `low`
- Max concurrent: 1

ถ้าชื่อหัวข้อใน UI ต่างจากนี้ ให้ใช้ส่วน Agent program ที่มีตัวเลือก Codex และปุ่มทดสอบ ค่าบนเครื่องนี้บันทึกในฐานข้อมูลเกมแล้ว ตรวจอ่านกลับจากอีก process สำเร็จ คีย์เข้ารหัสอยู่ใน `.env.server` ที่ถูก ignore ต้องเก็บไฟล์นี้คู่กับฐานข้อมูลเพื่อกู้คืน ไม่เก็บ token หรือคีย์ใน repository

ตั้ง **Table language → ไทย (Thai)** ในแคมเปญ การเล่าเรื่องจะเป็นไทยในบรรยากาศแฟนตาซี โดยรักษาชื่อเวท/ไอเทมที่มีอยู่และค่าระบบเป็นอังกฤษ Codex ใช้เครื่องมือเกมเพื่ออ่านสถานะ ทอยเต๋า และดำเนินการต่อสู้

เสียงแยกจากโมเดล: เปิด `npm run speech:edge` แล้วเปิด Narration ในแคมเปญ ดู [วิธีตั้งเสียง](edge-tts.md) การเริ่มโปรเจกต์ใช้ `npm run dev` บัญชีเล่นเกมยังต้องสมัครผ่านหน้าเกมตามปกติ ไม่มีการสร้างบัญชีหรือรหัสผ่านผู้เล่นแทนผู้ใช้

ทดสอบจริงแบบแยกฐานเกมได้ด้วย:

```sh
HARNESS=codex HARNESS_MODEL=gpt-6-luna HARNESS_TURNS=10 node scripts/smoke-thai-harness.mjs
```

สคริปต์ใช้โควตาบัญชี Codex ที่ล็อกอินอยู่ ไม่ได้รวมใน `npm test` เก็บ transcript ทุกเทิร์นใน `../.ogm-validation/live-thai-*` และปิด embeddings สำหรับการทดสอบพื้นฐานนี้ ผลดังกล่าวไม่ยืนยันคุณภาพ semantic retrieval ภาษาไทยระยะยาว

โมเดล `gpt-6.1-sol` ที่สืบทอดจากค่าก่อนหน้าถูก provider ปฏิเสธในการทดสอบเดิม ส่วน `gpt-6-luna` ผ่าน handshake, tool call, streaming และการตรวจขอบเขตเครื่องมือแล้ว ผลการเล่นจริงดู PROGRESS.md

ผลจริง: ผ่าน 10 เทิร์นภาษาไทย มีผลทอยจากระบบ 9 ครั้ง เริ่มการต่อสู้กับ Goblin และโจมตีด้วย Shortsword ผ่านเครื่องมือเกม ระบบปฏิเสธคำขอที่ผิดกฎสองครั้ง เทิร์นสุดท้ายทบทวนคำเตือนและร่องรอยจากต้นเรื่องได้ ใช้เวลา 13–26 วินาทีต่อเทิร์น เฉลี่ย 16.8 วินาที เป็นผลจากฉากทดสอบนี้ ไม่ใช่การรับประกันทุกแคมเปญหรือความจำระยะยาว
