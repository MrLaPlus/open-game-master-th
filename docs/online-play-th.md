# เข้าเล่นจากต่างบ้าน

## ขอบเขตที่กำลังเตรียม

เพิ่มทางเข้าเว็บเกมผ่าน HTTPS ด้วย Tailscale Funnel ให้เพื่อนเปิดลิงก์จากเบราว์เซอร์ได้ โฮสต์ล็อกอิน Tailscale ครั้งแรกด้วยบัญชีของตนเอง เพื่อนไม่ต้องติดตั้ง Tailscale และยังเข้าบัญชีเกม/ใช้รหัสเชิญตามเดิม

เป้าหมายคือตัวเปิดออนไลน์ครั้งเดียวที่เริ่มเกมและทางเข้า HTTPS พร้อมแสดงลิงก์ส่งให้เพื่อน เปิดซ้ำใช้การตั้งค่าเดิม และหยุดแชร์ได้เมื่อเลิกเล่น เครื่องโฮสต์ต้องเปิดอยู่ระหว่างเล่น

สถานะขณะเขียน: เตรียมไบนารีทางการแบบ userspace และตัวเปิด Linux แล้ว ตรวจ SHA-256 และรูปแบบสคริปต์ผ่าน ยังไม่มีลิงก์สาธารณะที่ยืนยันว่าเข้าเกมได้ ต้องล็อกอิน Tailscale และทดสอบก่อน

## เสียงยังอยู่ครบ

ไม่ได้ลบหรือปิดฟีเจอร์แชตเสียงสำหรับผู้ดาวน์โหลดเกมรายอื่น ผู้ใช้เครื่องนี้เลือกคุยผ่าน Discord จึงไม่ตั้งค่าพอร์ต WebRTC ให้ในรอบนี้

- **เสียง AI DM / Edge TTS:** เบราว์เซอร์รับเสียงผ่านเว็บเกม ส่วน bridge ที่พอร์ต 8881 ใช้ภายในเครื่อง ไม่ต้องเปิด bridge สู่สาธารณะ
- **แชตเสียงผู้เล่นในเกม:** เป็นระบบเดิมที่เปิดใช้ได้ตามปกติ แต่ HTTPS Funnel อย่างเดียวไม่พอ ต้องตั้งค่าเส้นทางสื่อและพอร์ต UDP/TCP ตาม [คู่มือเสียง](voice-and-dice.md)

การไม่ตั้งค่าเสียงให้โฮสต์นี้ไม่ใช่การตัดฟีเจอร์ออกจากซอร์ส และไม่ได้เปลี่ยนค่าตั้งต้นของทุกคน

## ไม่รวมในรอบนี้

ผู้ใช้ยกเลิกงานเพิ่มระบบสำรองเพื่อย้ายเครื่องในรอบนี้ ระบบสำรองเดิมของเกมยังอยู่ครบ ไม่มีการลบฟังก์ชันเดิม

## เกณฑ์ก่อนถือว่าเปิดออนไลน์สำเร็จ

1. โฮสต์ล็อกอิน Tailscale และอนุญาต Funnel ด้วยตนเอง
2. ลิงก์ HTTPS เปิดหน้าเกมจากนอกเครื่องโฮสต์ได้
3. ผู้เล่นล็อกอินและใช้รหัสเชิญเข้าแคมเปญได้
4. ข้อความ/ลำดับเทิร์นผ่าน SSE มาถึงต่อเนื่อง ทดสอบการเชื่อมต่อใหม่
5. เสียง AI DM ส่งผ่านเว็บได้ โดยไม่เปิดบริการเสียง localhost สู่สาธารณะ
6. ปิดและเปิดโฮสต์ซ้ำได้โดยไม่กรอกค่าทั้งหมดใหม่

อย่าใช้เพียงการเปิดพอร์ตหรือได้ชื่อ URL เป็นหลักฐานว่าผ่านทุกข้อ

## ตัวเปิด Linux (รุ่นทดสอบ)

จากโฟลเดอร์เกม ใช้ `npm run play:online` หรือรันไฟล์ `เปิดเกมออนไลน์.sh`

- ครั้งแรกดาวน์โหลดไบนารีทางการใน `data/online-tools/` และตรวจ SHA-256 หากยังไม่มี ไม่ติดตั้ง VPN หรือแก้ DNS ของระบบ
- ล็อกอินผ่านลิงก์ Tailscale ด้วยตนเอง แล้วเรียกคำสั่งเดิมอีกครั้งเมื่อเพิ่มเครื่องแล้ว
- ตัวเปิดใช้เว็บเกมเดิมที่พอร์ต 3000 หากยังไม่มีบริการที่พอร์ตนั้น จะเปิด `npm run dev -- --port 3000` ให้ จึงยังเป็นตัวเปิดสำหรับทดสอบรุ่นพัฒนานี้
- รอ endpoint สุขภาพตอบสำเร็จก่อนเปิด Funnel หากตั้ง Edge TTS localhost ไว้ จะเปิด bridge เมื่อยังไม่ทำงาน
- กด Ctrl+C เพื่อหยุดแชร์ และหยุดเฉพาะบริการที่ตัวเปิดเริ่มเอง หากคุณเปิดเกมแยกไว้ก่อน ตัวช่วยจะไม่ปิดโปรเซสเดิมนั้น
- `npm run online:status` ตรวจสถานะ และ `npm run online:stop` หยุดแชร์ URL โดยไม่ลบเกมหรือเซฟ

identity ของเครือข่ายและ log อยู่ใน `data/online-host/` ที่ไม่ติดตามด้วย Git ไม่ต้องส่งรหัสผ่านหรือคัดลอก identity นี้ให้ผู้อื่น ไม่มีการเพิ่มฟังก์ชันสำรองย้ายเครื่องในรอบนี้

ตัวช่วยออนไลน์นี้ยังรองรับเฉพาะ Linux x64/arm64 ผู้ดาวน์โหลดแพลตฟอร์มอื่นยังใช้เกมเดิมและตั้งทางเข้า HTTPS ของตนเองได้ ไม่ได้ลดแพลตฟอร์มที่ตัวเกมรองรับ

ยังต้องทดสอบจริงหลังล็อกอิน: ใบรับรอง HTTPS, การรับส่ง SSE, ล็อกอิน/รหัสเชิญ, เสียงอ่าน, origin ของโหมด dev และปิดเปิดซ้ำ ห้ามถือว่าผ่านจากการได้ URL เพียงอย่างเดียว
